# PalmAnnotate Swift

Versi iPad native SwiftUI dari PalmAnnotate. Proyek awal berisi pemilih modul Multisisi, Multisisi Video, dan Berat Tandan. [Rancangan iOS v1](DESIGN.md) mencakup alur pengumpulan, pengujian kompatibilitas Android, dan urutan implementasi.

## Jalankan di simulator

Gunakan Xcode dengan runtime simulator iPad dan [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
xcodegen generate
open PalmAnnotate.xcodeproj
```

Di Xcode, pilih skema **PalmAnnotate** dan simulator iPad, lalu tekan **Run**.
